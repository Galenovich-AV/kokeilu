# Как запустить сайт на Netlify с регистрацией учеников

Нужно сделать один раз. Займёт около 15 минут.

## 1. Supabase (база для аккаунтов и ответов)

1. Зарегистрируйтесь на https://supabase.com (бесплатно) и нажмите **New project**. Придумайте название и пароль базы, регион выберите **Europe**.
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла `supabase.sql` и нажмите **Run**.
3. Откройте **Project Settings → API** и скопируйте два значения:
   - **Project URL**
   - **anon public** key
4. Вставьте их в файл `config.js`:
   ```js
   window.SUPABASE_CONFIG = {
     url: 'https://xxxx.supabase.co',
     anonKey: 'eyJ...'
   };
   ```
   Этот ключ можно публиковать: доступ к данным защищён правилами из `supabase.sql`.
   Каждый ученик видит только свои ответы, а преподаватель видит все.

## 2. Netlify

1. На https://app.netlify.com нажмите **Add new site → Import an existing project → GitHub**.
2. Выберите репозиторий `kokeilu` и ветку с сайтом.
3. Настройки сборки уже заданы в `netlify.toml`, поэтому просто нажмите **Deploy**.
4. Скопируйте адрес сайта, например `https://suomi-xxx.netlify.app`.

## 3. Подтверждение email и адрес сайта

В Supabase откройте **Authentication → URL Configuration** и в поле **Site URL** вставьте адрес сайта с Netlify.
Тогда ссылки из писем (подтверждение email, смена пароля) будут вести на ваш сайт.

Если не хотите, чтобы ученики подтверждали email, отключите подтверждение:
**Authentication → Sign In / Providers → Email → Confirm email**.

## 4. Сделать себя преподавателем

1. Зарегистрируйтесь на своём сайте как обычный ученик.
2. В Supabase откройте **SQL Editor**, вставьте строку, указав свой email, и нажмите **Run**:
   ```sql
   insert into public.teachers (user_id) select id from auth.users where email = 'ваш@email';
   ```
3. Обновите сайт. Вверху появится кнопка **«Ответы учеников»**.

Там отображаются все ученики, их ответы и ошибки. Письменные работы можно оценить (taso) и оставить комментарий: ученик увидит его под своим текстом.

## Как добавлять новые темы

Темы хранятся в массиве `TOPICS` в начале скрипта в `index.html`. После изменений Netlify пересоберёт сайт автоматически.
